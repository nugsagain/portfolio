A self-hosted media platform I designed and run

By Evan Adiansingh · LinkedIn · Email

A private cloud server that hosts my audiobook, ebook and comic libraries and keeps them clean on its own: new books and comics are imported, matched, de-duplicated and organised automatically, backed up off-site every night, and I get a phone alert when something needs attention.

20+services in Docker
300+audiobooks & ebooks
1,600+comic issues
Nightlyoff-site backups & checks

What it does

One server, reachable securely from my phone, laptop, e-reader and TVs, and designed to need as little hands-on work as possible.

Book library

Audiobooks and ebooks live together: each book appears once with both formats, grouped into series in reading order.

Comic library

A checklist drives what gets collected, and the server builds reading lists for multi-series events, including 100+ issue reading orders.

Automation

Scheduled jobs import new arrivals, match ebooks to their audiobooks, fix series labels and rebuild reading lists without me lifting a finger.

Security

Services sit behind Cloudflare Tunnel and Cloudflare Access, with key-only SSH and secrets kept out of the code repository.

Backups

Encrypted nightly backups to Backblaze B2 with daily, weekly and monthly versions, proven by a real point-in-time restore.

Everywhere I read and watch

Reading progress syncs between my e-reader and the server, and the apps run on my phone, Fire TV and Samsung TVs.

How it fits together

New material comes in, gets checked and organised by automation, and lands in the libraries I actually use.

Problems I solved

Real production issues I noticed, tracked to their cause and fixed, each with a guard added so it can't come back.

Data recovery

Book descriptions changed after an import

NoticedSome audiobooks suddenly showed the wrong descriptions.
CauseEbook metadata files copied next to the audiobooks were overriding them.
FixRestored the originals from a point-in-time off-site backup, checked each item, and changed the importer so it can't happen again.
Pipeline

Downloads silently stopped starting

NoticedItems were "sent" but never arrived.
CauseNew links were piling up in the download manager's queue, which was never auto-confirming them.
FixTurned on auto-confirm, cleared the stale queue, and proved it with an end-to-end test download.
Data integrity

Series looked incomplete after a cleanup

NoticedSeries were missing books after duplicate entries were merged.
CauseThe series labels lived on the entries that were removed.
FixRestored every label from the backup, verified all series, and built a nightly job that keeps series tidy.
Quality

Duplicates and wrong editions

NoticedDuplicate books, collected editions repeating single issues, and one wrong-edition audiobook.
CauseLoose title matching and collections that bundle issues I already had.
FixStricter matching, page-count and edition checks against each book's copyright page, and a "single issues only" rule.
Reliability

Database busy errors during heavy imports

NoticedFiling comics failed with server errors under load.
CauseThe comic manager's database was locked while it processed new series.
FixAdded wait-and-retry handling, so imports finish cleanly instead of failing.

Rules the system enforces

I defined what "clean" means for my libraries; the automation checks it every night.

✓

No duplicates

Each book or comic issue exists once.

✓

Formats together

An ebook sits with its audiobook as one book.

✓

Single issues

No collected editions that repeat issues already owned.

✓

Tidy series, verified orders

One series per set of books, and reading orders taken from published guides, never guessed.

My role

  • Test every change and verify results before calling anything done.

How I build
